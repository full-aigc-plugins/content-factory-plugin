## Implemented contract

- Content Factory emits a VisualBrief tied to content revision and anchor;
- explicit approval is required before run;
- unavailable probe never calls generation;
- raw probe/run evidence is preserved;
- a successful result requires receipt id, artifact path, and valid
  artifact SHA-256;
- missing digest remains `invalid_receipt`;
- Content Factory does not implement image providers or generation logic.
