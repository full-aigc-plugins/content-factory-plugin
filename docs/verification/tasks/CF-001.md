# CF-001 — Immutable skill supply chain

Status: IMPLEMENTED_IN_BRANCH

## Scope

This task establishes the vendor-skill supply-chain mechanism. It does not yet admit a third-party vendor package. The production lock intentionally starts with an empty `sources` array so later vendor tasks cannot bypass source, license, immutable-ref, behavior, and digest review.

## Evidence

- RED commit: `2d73a3dd33041e0ea7f22de51e9ace9fafa20dc8`
- RED workflow: GitHub Actions run `35546087463`
- RED result: five supply-chain tests failed because the policy file and vendor manager were absent.
- GREEN evidence is recorded by the subsequent CI run for the implementation commit.

## Implemented contracts

- exactly one declared plugin-local skill: `content-harness`;
- semantic-version tag syntax for vendor refs;
- exact 40-character commit pin;
- per-skill SHA-256 digest requirement;
- recorded license requirement;
- cross-source collision rejection;
- vendor/local overlap rejection;
- undeclared or missing local-skill rejection;
- offline integrity check;
- optional online tag-to-commit verification;
- controlled update path that never treats a floating branch as an immutable release.

## Deferred by design

Actual third-party packages are added only by later vendor-integration tasks after license, package completeness, runtime dependencies, outbound behavior, and immutable source are verified.
