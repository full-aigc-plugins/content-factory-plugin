## Implemented contract

- workspace state lives under `.content-factory/`;
- SQLite database is `.content-factory/workspace.db`;
- object store is content-addressed by SHA-256 under `objects/<sha256>`;
- identical bytes deduplicate without changing their identity;
- exports and staging directories are created deterministically;
- schema version is persisted in `workspace_meta`;
- SQLite foreign keys and WAL mode are enabled;
- transaction helper commits all writes together or rolls all writes back;
- database lifetime has an explicit `close()`.

## Notes

The ObjectStore is the byte-level CAS only. Source/revision metadata, object
reference counting, migrations, retention and cleanup are owned by later
tasks.
